Sigilwright @VERSION@

Thanks for trying the demo. Play it the way you would any new game. Nobody needs to explain it to you.

HOW TO START
- Unzip everything. Keep the .pck file in the same folder as the program.
- Windows: run Sigilwright.exe. SmartScreen may warn because the build is not signed. Click "More info", then "Run anyway".
- Linux: run ./Sigilwright.x86_64

CONTROLS
- Move: WASD or the arrow keys
- Cast spell slot 1: left mouse button
- Cast spell slot 2: right mouse button
- Cast spell slots 3 and 4: Q and E
- Dash: Space
- Interact: F
- Loadout view: Tab
- Pause: Esc
- Send a report: F8
Keys can be changed in Settings > Controls.
