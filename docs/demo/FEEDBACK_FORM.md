# Friends demo feedback form

Thanks for trying the game! Answer these 8 questions in a message or a text file. Short answers are perfect.

1. How fun was it, from 1 (not at all) to 5 (a lot)?
2. Where were you confused?
3. What was the first spell you made?
4. What was the hardest room?
5. Would you play again?
6. Any bugs? What happened?
7. PC specs (CPU, GPU, RAM, OS).
8. Run time (shown on the end-of-run summary screen).

## During play

Press **F8** (rebindable in Settings > Controls) whenever something is weird or fun, type one line and press Save.

## How to send it to Franklin

1. Pause the game and click **Open reports folder**.
2. Zip the `reports` folder. Each report is a timestamped folder with `screenshot.png`, `run_log.json` and `note.txt`.
3. Send the zip together with your answers through the same channel the demo was shared on.

If the button does not open anything, the folder is here (the game's name is Sigilwright):

- Windows: `%APPDATA%\Godot\app_userdata\Sigilwright\reports`
- Linux: `~/.local/share/godot/app_userdata/Sigilwright/reports`

## Privacy

A report contains a screenshot, the run log and the note you typed. It is stored only on your PC and nothing is uploaded automatically.
